Building Transformers: Forged to Fight Offline

A complete technical onboarding manual & build guide for the upstream development branch without custom DSL dependencies.

1. Overview

Transformers: Forged to Fight (v9.2.0, build 123129100) was an online-only, server-authoritative mobile fighter powered by Unity IL2CPP. When official servers shut down, the game became unplayable.

The open-source revival repository (canonical upstream: Gummygamer/Transformers-Forged-To-Fight-Offline-Version, branch development) allows the unmodified game client to run 100% locally on Android devices without external servers or internet connection.

2. The "Legible" Trap: Why People Say It's Hard to Build

⚠️ The Toolchain Bottleneck
Upstream author Darabat migrated all Python build scripts and mock servers into a custom, in-house programming language named Legible (.lbl).

When newcomers run the upstream Windows launcher (launch_windows.bat), the script attempts to:

  • Download and install Visual Studio 2022 C++ Build Tools via winget (>2 GB, requires admin permissions).
  • Download and install the Rust/Cargo toolchain via rustup.
  • Fetch the legible-lang repository and compile the legible interpreter from source code.

In containerized environments, cloud agents, or standard developer setups, this process frequently fails due to missing MSVC build tools, PATH synchronization issues, or compiler version mismatches.

💡 The Agent / Python Alternative
The underlying APK modification has zero runtime reliance on legible! The game engine is standard ARM64 Unity IL2CPP, and the in-app server is compiled from pure C. By substituting the .lbl build drivers with clean Python 3 scripts, the entire project builds in under 30 seconds without Visual Studio or Rust.

3. How the Standalone Offline Architecture Works

To run completely self-contained without a PC server running in the background, three synchronized components work together:

  1. In-APK Loopback HTTP Server (inapk_server.c): A lightweight micro-server compiled into libdothook.so. It starts as a background thread on constructor launch, binds to 127.0.0.1:8080, and answers Sparx API requests.
  2. Baked Binary Payload (assets/payload.bin): Contains ~19,300 pre-serialized JSON routes (roster definitions, 5-star upgrades, 5-member squads, campaign quest maps, dynamic dialogues) mapped directly by the micro-server.
  3. Binary Patches in libil2cpp.so: Patches 16 critical functions to bypass TLS certificate pinning, certificate validation, null alliance pointers, profile level locks, and redirect DNS requests to loopback.

4. Toolchain Setup (Clean Machine)

Assume starting on a machine with nothing installed. Install only these four lightweight components:

1. Python 3.10+ & Capstone

pip install capstone

2. Java OpenJDK 17 (or 21)

Required for running Android apksigner and keytool:

# Set JAVA_HOME in your environment
$env:JAVA_HOME = "C:\Program Files\Java\jdk-17"
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"

3. Android NDK (r26b or r26d)

Provides the LLVM Clang cross-compiler targeting aarch64-linux-android28:

Download from Google NDK Archive and extract to toolchain/android-ndk-r26b.

4. Android SDK Build-Tools

Provides zipalign.exe and apksigner.bat (from build-tools 34.0.0 or 35.0.0). Extract to toolchain/android-sdk.

5. Original Game APK

You need the official unmodified APK release:

com.kabam.bigrobot_9.2.0-123129100_minAPI23(arm64-v8a,armeabi-v7a)(nodpi)_apkmirror.com.apk

Size: ~834 MB • SHA256: 0a996f2648fbbe9be80a6b7d15904ce204128549603f021f153a0f7893116f1f

6. The 5-Stage Build Pipeline

1
Compile Native Hook (libdothook.so)
ARM64

Compiles the hook library containing the in-APK loopback server and 60 FPS unlock. Uses NDK Clang directly:

$CLANG = "toolchain/android-ndk-r26b/toolchains/llvm/prebuilt/windows-x86_64/bin/aarch64-linux-android28-clang.cmd"

& $CLANG -shared -O2 -fPIC -Wl,-soname,libdothook.so `
    -o "tools/nativehook/libdothook.so" `
    "tools/nativehook/hook.c" `
    "tools/nativehook/inapk_server.c" `
    -llog
Upstream Feature Highlights in hook.c
Includes 60 FPS target framerate patch on Application/QualitySettings, Android 15+ 16 KiB memory page alignment, and removed runtime FIXSYN poke (migrated to static IL2CPP patch).
2
Extract & Statically Patch libil2cpp.so
Python + Capstone

Extract pristine lib/arm64-v8a/libil2cpp.so from the base APK. Apply all 16 static disassembly patches:

Strict In-Place DT_NEEDED Injection:

Instead of patchelf (which shifts ELF segments and can crash Android Bionic's linker on modern devices), reuse an identical duplicate symbol inside .dynstr (_ZNSt6__ndk17codecvtIDsc9mbstate_tED1Ev) for string libdothook.so\0, and point the spare DT_NULL in .dynamic to it.

3
Export Offline Server Payload (payload_test.bin)
Python

Bakes all static endpoints in Server/responses/ along with procedural 5-star characters, stats, and 11-tile mission maps into an aligned binary table:

python Server/export_payload.py --out build/payload_test.bin
# Output: wrote build\payload_test.bin: 10993844 bytes, 19389 entries, port 8080
4
Repackage Phone APK
Python

Run Server/build_phone_apk.py to assemble the unsigned APK:

python Server/build_phone_apk.py <base_apk> build/phone-unsigned.apk `
    --scheme http `
    --server-host 127.0.0.1 `
    --server-port 8080 `
    --bundle-server `
    --patched-il2cpp build/libil2cpp-arm64-patched.so
  • Injects lib/arm64-v8a/libil2cpp.so and lib/arm64-v8a/libdothook.so.
  • Embeds assets/payload.bin (stored uncompressed for mmap).
  • Binary-patches global-metadata.dat and globalgamemanagers (QualitySettings).
  • Strips unused 32-bit binaries to keep APK slim.
5
Zipalign & Apksigner
Android SDK

4-byte memory alignment and v1/v2/v3 signing:

# 1. 4-byte memory alignment
& "toolchain/android-sdk/build-tools/34.0.0/zipalign.exe" -f -p 4 `
    build/phone-unsigned.apk build/phone-aligned.apk

# 2. Sign with debug keystore
& "toolchain/android-sdk/build-tools/34.0.0/apksigner.bat" sign `
    --ks build/debug.keystore `
    --ks-pass pass:android `
    --out build/Transformers-9.2-offline-development.apk `
    build/phone-aligned.apk

7. Automated One-Click Build Script (build_apk.py)

All 5 stages above can be triggered with a single command:

python build_apk.py

The complete orchestrator source is provided below for immediate drop-in use:

#!/usr/bin/env python3
import os, subprocess, sys, zipfile
from pathlib import Path

ROOT = Path(__file__).resolve().parent
BUILD_DIR = ROOT / "build"
BUILD_DIR.mkdir(exist_ok=True)
BASE_APK = Path(r"e:\Agent\TFTF\com.kabam.bigrobot_9.2.0-123129100_minAPI23(arm64-v8a,armeabi-v7a)(nodpi)_apkmirror.com.apk")

def main():
    target_apk = BUILD_DIR / "Transformers-9.2-offline-development.apk"
    print("=== Building Offline APK for Upstream development ===")

    # 1. Compile native hook
    clang = ROOT / "toolchain/android-ndk-r26b/toolchains/llvm/prebuilt/windows-x86_64/bin/aarch64-linux-android28-clang.cmd"
    subprocess.run([
        str(clang), "-shared", "-O2", "-fPIC", "-Wl,-soname,libdothook.so",
        "-o", str(ROOT / "tools/nativehook/libdothook.so"),
        str(ROOT / "tools/nativehook/hook.c"),
        str(ROOT / "tools/nativehook/inapk_server.c"), "-llog"
    ], check=True)

    # 2. Extract & Patch libil2cpp.so (16 sites + DT_NEEDED)
    patched_so = BUILD_DIR / "libil2cpp-arm64-patched.so"
    if not patched_so.exists():
        fresh_so = BUILD_DIR / "libil2cpp-arm64-fresh.so"
        with zipfile.ZipFile(BASE_APK) as z:
            with z.open("lib/arm64-v8a/libil2cpp.so") as src, open(fresh_so, "wb") as dst:
                dst.write(src.read())
        subprocess.run([
            sys.executable, "patches/patch_il2cpp.py", str(fresh_so),
            "--abi", "arm64-v8a", "--apply", "--needed", "inplace", "-o", str(patched_so)
        ], check=True)

    # 3. Export offline payload
    subprocess.run([sys.executable, "Server/export_payload.py", "--out", str(BUILD_DIR / "payload_test.bin")], check=True)

    # 4. Package phone APK
    unsigned_apk = BUILD_DIR / "phone-unsigned.apk"
    subprocess.run([
        sys.executable, "Server/build_phone_apk.py", str(BASE_APK), str(unsigned_apk),
        "--scheme", "http", "--server-host", "127.0.0.1", "--server-port", "8080",
        "--bundle-server", "--patched-il2cpp", str(patched_so)
    ], check=True)

    # 5. Zipalign & Apksigner
    aligned_apk = BUILD_DIR / "phone-aligned.apk"
    zipalign = next((ROOT / "toolchain").glob("**/zipalign.exe"))
    apksigner = next((ROOT / "toolchain").glob("**/apksigner.bat"))
    subprocess.run([str(zipalign), "-f", "-p", "4", str(unsigned_apk), str(aligned_apk)], check=True)
    subprocess.run([
        str(apksigner), "sign", "--ks", str(BUILD_DIR / "debug.keystore"),
        "--ks-pass", "pass:android", "--out", str(target_apk), str(aligned_apk)
    ], check=True)

    unsigned_apk.unlink(missing_ok=True)
    aligned_apk.unlink(missing_ok=True)
    print(f"[OK] Build Complete: {target_apk} ({target_apk.stat().st_size / (1024*1024):.2f} MB)")

if __name__ == '__main__':
    main()
